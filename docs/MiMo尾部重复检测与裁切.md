# MiMo完整朗读后的尾部重复：检测与裁切

已接入MiMo统一质量核心，支持英文与中文比较。机制位于生成后的本地质检层，不修改MiMo权重，不需要自行训练模型，复用已有SenseVoice。旧转换入口没有自动启用统一核心；需显式启用后才生效。

## 判断与处理顺序

1. 将完整音频转写与实际朗读文本比较。只有呈现“完整正文 + 原文连续片段的额外重复”才继续；原文内部本来就有的重复保留，任意新增内容、中途重复、疑似漏读不自动裁切。
2. 在音频内部寻找至少300ms的低能量停顿。最多检查六处停顿，每处分别转写前缀和尾段，最多十二次诊断ASR；不靠句长估计直接切音，也不依赖SenseVoice未提供的逐词时间戳。
3. 要求保留前缀覆盖完整正文，移除尾段只包含原文中的连续重复。切点两侧各至少100ms低能量保护；没有安全停顿就不做本地尾部裁切，其他自动修复仍受既有请求额度约束。当前只处理PCM16 WAV，超过180秒的单块跳过专项检查。开始每个探针及两次转写之间检查剩余运行时间，不能硬中断正在执行的单次模型推理；检测时间另存并计入本地评估耗时。
4. 自动模式仅接受前缀严格对齐、重复片段位置唯一、正文不是过短或高度重复的文本。较长正文中小幅转写差异只允许输出人工候选；首版上限为正文不少于12个比较单元、错误率不超过12%、无删除且末三个单元一致。此宽松条件不获得自动裁切资格。
5. 自动候选重新检查内容、信号和一致性，并重检相邻完整左右句。必须改善优先级、保留原有通过检查、不增加已知内容差异或严重错误才能选用。未选用的尾重复候选交给人工，不为其连带的接缝ASR提示重新生成邻句。

原音频和候选同时保留，切掉的诊断尾段也留存。保留语音PCM逐样本不变，不淡化语音尾音。记录原件／候选／ASR模型指纹、比较结果、切点样本数和操作版本；缓存恢复时重验来源与安全切点。开关及策略版本进入选中结果的缓存键，关闭专项检查不会恢复该策略选出的裁切版本。

ASR也可能识别错误或产生幻觉，因此严格模式仍是自动筛查与修复规则，不等同人工金标准。没有安全停顿、混合语言、短语气词、高度重复文本及正文对齐不明确时可能需要人工处理；首版不承诺覆盖所有多读。

### 短词多次发音尝试：C’mon个案

Flipped首章R034（Juli，原章239.00–244.92秒）经用户确认有两三次发音尝试。将三处尝试分别转写，均未能证实某次正确完整；因此没有套用“保留首次完整朗读”的尾部裁切。此类属于重复／发音重启问题，但不满足当前自动裁切前提。

本次仅针对这一处，把合成文本展开为“Come on!”，保留书中“C’mon!”及来源区间，以原Chloe预设生成一次，并匹配章节音量。其余99块及此前已确认的三处修复不变。新音频1.76秒，两组完整相邻上下文均识别为一次Come on；孤立转写为Comome on，仍保留发音复核提示，不能据此宣称人工通过。该处理是可追溯的单处修复，没有启用全局缩写替换或新增自动读法修复规则。

新候选：[试听页](../listening_review/flipped_cmon_repair_20261017/index.html)。证据：[单处修复验证](validation/audio_core_20261017/flipped_cmon_repair_v48.json)。短词发音重启与普通尾部重复宜分开记录，避免用不确定的“第一遍”裁切得到缺词或错误发音。

后续人工结论（v49）：用户确认“只读一次，发音与接缝均正常”，已绑定实际R034和上下文，见试听目录的`human_acceptance_v49.json`。孤立转写误报通过正式人工裁决另存派生报告；原机器报告未改，短句声纹未完成仍保留。此结论不扩展为整章或全部质量维度通过。

## 如何启用

默认`tail_repeat_mode=review`：统一核心检测并导出候选，保持原音频。主界面质量报告的试听范围中增加`tail_repeat:<块编号>`，文件指纹不匹配时不提供该候选。

需要自动选用严格候选时，CLI在现有转换参数后增加：

```bash
--audio_core_enabled --audio_core_repair \
--audio_core_tail_repeat_mode auto \
--audio_core_asr_model .audio_quality_models/SenseVoiceSmall \
--audio_core_max_repairs 0 --audio_core_max_repair_characters 0
```

这里设置0用于禁止追加重合成，本地裁切仍可运行；初次生成依旧占用初始请求额度。其他已启用的本地修复规则也照常生效。

WebUI在高级设置中启用“MiMo统一质量核心”和自动修复，上传[自动裁切配置](../examples/audio_core.tail_repeat_auto.settings.json)。模型路径需在实际机器存在，并在安装评估依赖的环境启动；不自动下载模型。只要候选供试听可使用默认`review`；`off`关闭此专项检查。无本地ASR时无法完成内容检测，保留未完成状态。

质量报告新增`tail_repeat_checks`，保留完整诊断及自动选用状态。`selected=true`仅表示机器选择，不写成人工通过。既有质量报告可照常读取；本次没有更改TTS请求缓存或上传书籍／参考音频。
