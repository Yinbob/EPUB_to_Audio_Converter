# MiMo 网页生成使用说明

当前目标是上传一本书、为人物固定声音、导出章节音频。论文实验、Qwen TTS 和 VoxCPM 的新适配暂缓；已有其他引擎入口保留。

在项目目录运行 `python3 main_ui.py`，默认地址为 `http://127.0.0.1:7862/`。系统 Python 启动时优先使用已配置的 `venv_audio_quality/`，没有时回退 `venv_chatterbox/`。如果已经激活其他虚拟环境，会保留当前选择；要明确使用已配置的质检环境，可运行 `./venv_audio_quality/bin/python3 main_ui.py`。启动不安装依赖，不下载模型。

1. 启动项目网页，上传 EPUB／DOC／DOCX。单本书上传后会在本地自动读取目录，在「起始章节」「结束章节」按名称选择连续范围，也可输入关键词搜索。只生成一章时，两端选择同一章；反向选择时，另一端会收拢到刚选择的章节。下方显示范围、章数和字符数，并用移动高亮带表示范围。目录、版权页可能也计作章节；例如 Flipped 的 Diving Under 是第 5 项。多本书批量处理仍使用数字范围。高级解析设置改变后会重新读取目录并恢复全书范围，请重新选择；读取目录不会调用模型。
2. 选择 MiMo。MiMo 和 DeepSeek 的配置可在页面填写并保存；MiMo 合成音频，DeepSeek 用于拆分人物与对白。点击拆分或合成会把相应正文发送给当前配置的服务。
3. 打开「为旁白和人物使用不同声音」，点击「生成 / 重新拆分剧本」。无需上传 JSON。上传后自动拆分默认关闭，避免只想选书就触发请求。默认仅分析选定章节的人物和对白；只有勾选「同时分析全书人物」才额外发送其他章节，合成仍限选定范围。先试一章、随后逐章扩展时，会保留已保存的人物声音。

   自动拆分现在为每个所选章节额外进行一次叙述视角分析，再将候选身份和原文证据提供给分段模型。第一人称自述仍属于叙述，但由该人物声音朗读，并与其对白共用声音档案；跨章或章内换叙述者可使用不同人物。第三人称或证据不足的叙述保留默认旁白供核对，不按书名或奇偶章猜测。超长章节预分析只读取首尾各12000字符，中段视角仍由逐段拆分判断。失败时继续逐段识别，不自动重试预分析。逐段模型明确选择本章候选人物时，可复用该候选已定位的身份引文，无需每段重复；不会由此把全章强行改给该人物。模型漏返段落类型时使用现有每块最多2次的重试，仍失败保留原文并标为待复核；不强行猜测类型。人物自述中的动作描写和“他说”等提示语也应沿用该人物的声音。
4. DeepSeek 连接配置和剧本导入在准备区对应页签中；拆分期间下方持续显示当前阶段，切换准备页签也能看到等待提示。生成后进入「角色声音」，选择「当前人物」，调整左侧音色、语言和语速，点击「应用当前人物的声音设置」，再在右侧试听。主要人物推荐固定参考，次要人物可先使用差异明显的内置声音；描述声音的多次生成仍可能变化。
5. 满意的试听可点击「固定这次试听的音色」。本步只在本地保存，下一次试听或生成将这条参考上传给 MiMo。也可以上传自己的已确认 PCM16 WAV 参考。参考和指纹存放在 `audiobook_output/.voice_references/`，不会依赖上传临时文件长期存在。
6. 在「剧本与归属」核对人物、章节及新增的「叙述声音」列；查看待复核段落可见叙述／对白类型、朗读人物及原文证据，必要时选择正确人物并确认。单一叙述者的章节，可在「本章叙述声音」选择章节和人物，点击「应用本章叙述声音」，一次修改本章所有已识别的叙述段并复用该人物声音；对白不变。章内多视角仍逐段纠正，旧剧本无叙述类型时需先重新拆分。应用时一并保存当前声音参数，成功后需重新确认。「高级工具」提供完整参数表及所有人物的语速校准，校准会为每个角色调用一次 MiMo。检查后点击工作区底部「确认剧本与角色参数」，再点击页面下方「开始生成」。自动生成的 V2 人物项目会保存当前声音设置；后续处理同书章节时复用已保存的声音身份。改动设置后要重新确认。旧剧本可继续读取，但不会凭空补出叙述身份；需要选定对应章节后重新拆分。明确人工确认且原文边界未变的归属保留，历史机器默认旁白可以重新判断。
7. MiMo 默认启用音频检查，自动发现本机已有的 SenseVoice／ECAPA 目录，不会为此自动下载模型。使用克隆声音时，质检自动复用该角色的克隆参考音比对声纹和音高，跨章仍使用同一份参考；没有参考文本时不据此判断语速。报告中的 `clone_conditioning_reference` 仅表示使用了克隆输入，不表示人工验收通过；已有匹配的人工核验参考档案时优先使用后者。声纹阈值仍是未校准的筛查规则，短于三秒的有效语音可能无法比较。默认不自动修复；需要时勾选自动修复，可能产生额外合成请求。该检查开启时采用单 worker，并避免叠加旧的 DeepSeek 质量重试流程。
8. 完成后到「资源库」试听和下载。生成页的「生成后查看检查结果」提供报告和问题片段；批次结束后自动载入当前输出目录中的报告，也可手动刷新。警告包括疑似异常和未校准项目，不等于音频一定有错。

本轮验证包含声音档案到实际 PCM 导出、质量报告和资源库文件的离线链路；合成服务以替身调用，未产生新的付费语音请求。以已接受的 Flipped 首章为听感目标，但其人工确认过的增益、停顿和局部裁切不能直接当成适用于所有书籍的参数。新书整章的最终听感仍需使用真实合成结果判断。

真实DeepSeek已验证Flipped的Diving Under与Flipped两章的叙述声音归属提议，经历一次首轮分析及三个问题块复核，再加1次开头类型核对，共19次文字请求。最终两章均有完整段落类型，人物自述分别归属Bryce／Juli；未生成新语音或替换已有声音项目。具体范围与限制见[真实叙述验证记录](validation/narration_identity_20261017/README.md)。

拆分等待提示修复：点击生成／重新生成后，按钮附近会显示独立等待动画、当前阶段及已等待时间；完成或失败后更新结果并恢复按钮。该状态区不依赖被全局样式隐藏的原生等待遮罩，也不显示估算百分比。服务更新后需刷新已打开的网页。离线链路已验证，实际新动画尚无浏览器验收，见[验证记录](validation/role_split_feedback_20261017/README.md)。

重新拆分会作废上次确认：拆分期间需等待，完成或失败后核对当前剧本，再点击确认后生成。正在合成时，请先等待结束或停止，再重新拆分。关闭页面不会取消已经开始的拆分；再次提交同书时会提示等待。相关并发与恢复流程已通过离线检查，见[状态保护记录](validation/role_resplit_guard_20261018/README.md)。
