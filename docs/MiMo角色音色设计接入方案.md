# MiMo 长篇书籍混合角色声音方案

日期：2026-10-17。全书统计、混合分配、固定声音卡和双模型请求已实现，并已生成六条英语 VoiceDesign 探针；共同探针已由用户确认内容、同角色一致性和两角色可区分。三个混合场景的响度匹配版也已通过本轮指定内容、Taylor跨章声音、接缝、音量及旁白语速检查，原机器告警保留。原方案快照和既有九章内置声音基线保留。具体命令和本轮边界见 [MiMo混合选角使用与验收](MiMo混合选角使用与验收.md)。

## 1. 范围与预期结果

首版只使用两个 MiMo 模型：内置声音用 `mimo-v2.5-tts`，描述声音用 `mimo-v2.5-tts-voicedesign`。不适配 MiniMax，不引入金额计算。英语优先，中文使用同一流程但独立核验声音。VoiceClone 仅是描述声音稳定性不足时的后续验证选项，不是首版默认要求。

目标是将少量已核验的内置声音用于反复出现、对白量大的角色，同时为其他角色提供固定声音描述。不能仅因出场间隔大就认为声音漂移无影响，也不宣称所有生成声音都容易辨认。

## 2. 先建立全书角色统计

先完成全书剧本预分析，保留原文、合并角色别名，并使用持久角色 ID。旁白单独统计，不参加普通角色排名。现有 V2 角色登记表可复用；归属未确定的对白保持待核验，不自动把它归给主角。

每个角色输出：

| 统计项 | 计算方式及作用 |
|---|---|
| 对白读数 | 英语按词、中文按汉字；复用现有 reading_count，记录语言与计数版本 |
| 预计对白时长 | 用统一基准语速估算，英语初始150词/分，中文初始240字/分；仅为分配估计，不代表实测语速 |
| 对白轮次 | 同章连续同角色片段合并后计数，避免分块大小改变角色排名 |
| 出场章节 | 保存全部章节在本书中的有序位置，不能仅用第一章和最后一章 |
| 出场间隔 | 相邻两次出场之间缺席的章节数，保留最小值、中位数和最大值；单次出场记不适用 |
| 单章最大对白量 | 识别“全书对白不多，但某一章长时间讲话”的角色 |
| 互动关系 | 复用现有相邻对白互动图，记录经常交谈的对象；该统计尚不等于完整场景理解 |

内置名额按预计对白时长降序分配；相同时按出场章节数、互动权重、角色 ID 依次确定。不要只按被分成多少段来排名，也不要把故事重要性假装成已测量的对白量。所有估计参数及原始读数写入角色统计文件。

对于未获得全书剧本的局部任务，必须标记“局部统计”，不能保证选到全书说话最多的人物。首版自动全书分配要求完整预分析，生成进度不反向改变已锁定角色身份。

## 3. 确定内置容量，再分配角色

设 V 为目标语言下，已完成人工核验且实际身份不同的内置声音数。`mimo_default` 不能作为额外独立声音名额。当前英语先导库仅有 Mia、Chloe 两种通过核验的声音；官方目录不等于本项目合格库。

默认有旁白时预留一个内置声音，可配置关闭。用户已锁定的分配优先，并扣除其实际占用的声音名额。剩余可用声音数记为 K：

1. 对尚未锁定的角色按全书预计对白时长排名，前 K 名优先获得剩余内置声音。
2. 对这些角色，复用互动图选角：经常交谈的角色优先获得实际探针差异较大的声音，同时尊重用户锁定和已审查的适配条件。无适配评分时显式标记未启用，不能当作已证实适合。
3. 自动分配的内置声音默认不复用；容量之外的角色进入描述声音分支。若某个高频角色没有可接受的内置候选，则作为例外转入描述分支并保留原因，不强行分配不适合的声音。
4. 只有用户明确设置共享声音，才保留这种共享约束；不能悄悄恢复旧版轮流复用策略。
5. K=0 时，除已锁定分配外的角色全部进入描述分支，不能伪造更多合格声音。

例如，若有4个经核验可用的内置声音且旁白占1个，其余3个优先分给对白最多的3名角色。当前英语库只有2个时，默认只剩1个名额分配对白角色；后续可通过额外核验扩大内置库。

## 4. 其他角色的描述声音分支

所有没有内置名额的角色均可设计声音，但检查强度不同。首轮可配置的保守起点如下；这些是待检验的工程参数，不是已证明的最优阈值：

| 类型 | 初始判断 | 策略 |
|---|---|---|
| 稀疏短对白 | 全书预计对白≤90秒、出场≤3章、单章≤45秒；重复出场时每次至少间隔2个完整章节，单次出场不检查间隔 | 固定声音卡直接 VoiceDesign，检查跨文本及重复请求 |
| 其他描述角色 | 不满足上述任一项，包括内置名额不足而未入选的高频角色 | 同样固定声音卡，但增加跨章／连续多段一致性核验，保留固定角色锚点 |

“隔好几章出现”只决定风险分层，不表示可以每次生成新的角色身份。两类角色均全书复用同一声音卡，禁止随章节改写身份描述。

声音卡由 LLM 根据已知角色特征生成，包含声区、共鸣、音质、发音习惯、口音、语言和固定版本。缺失年龄／性别等信息不冒充原作事实。当前句的情绪另存 tone，不放进永久身份描述。先为一名角色生成一份候选，发生明确问题时才提出有记录的新候选，不默认给每个路人反复海选。

生成时同时参考其主要对话对象，避免与已分配角色在声区、质感和共鸣上完全相近；正式判断使用实际音频，不能把文字描述差异当作已证明的可辨识性。避免依靠极端快慢或整体音量差异区分身份。

## 5. MiMo 请求与缓存

模型按角色路由，不能只设置一个全书 model_name：

| 角色模式 | 模型 | 请求声音条件 |
|---|---|---|
| preset | mimo-v2.5-tts | audio.voice 为合格内置声音 ID |
| design | mimo-v2.5-tts-voicedesign | user 消息包含固定声音描述及当前表演指令，audio 不传内置 voice |

两者都将准确正文放入 assistant 消息。设计模式显式关闭 `optimize_text_preview`，避免正文润色；首轮使用非流式 WAV。描述不能混入正文要求模型朗读，也不能将剧情动作或角色姓名自动插入正文。模型由本地模式枚举映射，不能让 LLM 任意填写未知模型名。

应用内部为描述声音保存角色声音档案 ID；这个 ID 不作为预置 voice 传入 MiMo。保存 role_id、voice_mode、实际模型、voice_description、instructions、语言、版本、状态及已核验锚点。provider_params 校验器已显式扩展，不能依靠忽略未知字段实现。

缓存至少绑定实际模型、实际文本、完整有效指令、输出参数及声音卡版本／哈希。声音卡更改时，相关角色产物和质量报告失效；其他角色不必重合成。参考音频路线未来还需绑定参考文件内容哈希。每次线上调用单独记录，不隐藏自动重试或分块；仅记录次数、字符量、时间和文件，不计算金额。

## 6. 稳定性、修复和失效处理

全书分配确认后锁定，不边合成边根据已读章节重新排序。预分析发现后期配角变主角时，已在全书排名中处理；书籍新增章节或角色归属大改时另建分配版本，不能从中途开始换声。必要的换声必须重建该角色全部受影响片段。

每名描述角色以首个内容完整、信号合格且经试听确认的片段建立固定锚点，跨章比较仍使用该身份锚点，不只与当前章最近一段比较。中文、英文锚点分别核验；不自动把疑似异常片段更新为参考。

质量检查仍按原优先级：拼接断音／漏音／停顿，一致性，重复漏读及多读，信号与响度。正常角色切换不算音色漂移。声纹、音高和语速规则先作提示，未校准阈值不直接宣称真实缺陷。描述声音若持续漂移，标记待处理并在有限重试范围内处理；不会静默换回 Mia 或另一份声音描述。固定参考＋VoiceClone 仅在单独验证后启用。

新声音单独测量响度，不能沿用 Mia 0 dB／Chloe -5 dB 的先导设置。比较材料使用统一响度协议，所有处理后再检查接缝及内容。

## 7. 按依赖顺序实施与检验

| 阶段 | 改动／产物 | 验收 |
|---|---|---|
| A 统计与分层 | 新增角色统计及混合分配模块，导出 role_usage.json、hybrid_casting.json；复用现有互动选角 | 纯离线验证长篇角色排名、旁白名额、锁定覆盖、分块不影响排名、角色不足及局部输入标记 |
| B 角色声音卡 | 扩展剧本输出和参数校验，保存有版本的声音档案 | 缺描述、未知模式、原文变化被拒绝；同角色跨章复用同一档案；用户字段不被覆盖 |
| C 双模型请求 | 改 provider 的统一核心、角色合成和普通模式请求构造，复用同一模式解析 | mock 检查实际模型／消息／audio 参数，模式缓存隔离，改描述失效；旧内置声音行为保持 |
| D 声学先导 | 优先复用已核验内置探针；两名描述角色各2条共同英文文本＋其中1条独立重复，共6次新设计请求，先导不自动重试 | 重复测试显式绕过缓存；逐次保存原始响应；ASR及信号检查并结合人工核验，比较跨角色差异及同角色重复变化 |
| E 混合章节 | 新建少量自编混合对白，含主要角色与配角对话、同一配角隔章再现；另存全部音频和质量报告 | 全文完整、接缝保留、同角色跨章一致性可接受、响度衔接自然；不覆盖原九章 |

先做A，再做B/C，离线检查通过后才做D，D通过后再做E。不先跑整本书。统计可用12章以上的构造剧本覆盖长间隔、后期对白增多等边界，这类夹具不计真实研究样本。

现有声学先导只有三个角色，不能证明长篇频率策略有效。旧九章全部为预置声音，仅用于原有基线，不追认成混合分配结果。

## 8. 后续研究比较

可比较：原内置声音复用、按对白量的混合分配、对白量＋互动约束＋固定声音卡的混合分配。混合方法之间保持可用内置库、模型、描述候选数和质量处理协议一致；预置与混合分支的请求量分别报告，不把模型差异全归于算法。

分别统计高频角色辨识、稀疏角色再出现时辨识、跨章一致性、真实内容／拼接问题、人工干预和重生成次数。最终辨识收益需要独立听众与多本书；工程先导和声纹距离不能替代这些证据。

研究问题可表述为：在内置声音有限的长篇有声书中，基于对白分布分配稳定声音资源，并用角色互动约束设计其他声音，能否降低角色混淆而不损害跨章一致性。
