# 剧本归属工作流

先确认“由谁朗读”，再配置“用什么声音”，最后统一确认。日常路径为：生成剧本 → 剧本归属 → 角色声音 → 复核与确认 → 页面下方开始生成。

归属页每次只展开一种工作：章节叙述者、逐段核对、人物合并。前者仅批量修改已识别的叙述，后者保留逐段修正。合并是独立修正工具，提前显示源人物、目标人物、影响段数及保留目标声音；不与段落说话人混用。锁定声音与参数批量编辑留在高级工具。

保存动作只保存当前修改，不启动合成。局部保存结果紧邻操作按钮，区分等待、保存成功和失败；不被段落详情刷新覆盖。合并后刷新所有人物下拉，移除已经并入的人物，避免使用过期选项。

最终确认只出现于“复核与确认”页签。显示现有剧本摘要及确认状态；所有修改沿用后端失效确认规则。主生成按钮仍位于现有生成卡片。

保留 Apple 玻璃材质、主题色、圆角及完整动效；单一工作面降低滚动和按钮竞争。桌面工具选择与工作面并列，窄屏上下排列；默认、空态、读取中、失败与成功状态均可理解。

验证范围：离线状态、持久化和 Gradio 接线；浏览器访问限制沿用，不绕过，不把源码检查描述为视觉验收。
