# 剧本归属工作流重构 · 2026-10-19

先写使用逻辑，再重构现有 Apple 玻璃界面。设计见 [DESIGN.md](DESIGN.md)。

## 最终路径

1. 剧本归属（默认）：左侧选择章节叙述者、逐段核对或人物合并，右侧一次只显示对应任务。
2. 角色声音：沿用声音预设、描述、克隆、语速、试听及固定参考；下一步进入复核。
3. 复核与确认：集中显示剧本摘要，唯一的最终确认按钮只在此页。修改后沿用后端撤回确认规则。
4. 页面下方原有「确认并生成」卡片启动合成。

归属保存不启动合成。人物合并先展示源→目标、影响段数、保留目标声音；保存时先返回等待状态，保存成功后在按钮附近展示具体结果。结果控件与段落详情分离，避免刷新详情覆盖保存提示。刷新人物列表会移除已合并人物；段落和声音锁可以选择旁白，合并的两侧均不能选旁白。声音锁、批量参数与校准留在高级工具。
