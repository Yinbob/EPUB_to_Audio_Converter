## 能支持什么，不能支持什么

当前可支持：已跑通人工回填、来源与音频完整性检查、匿名编号及四维描述性汇总；用户发现的衔接自然度问题是真实后续需求。

当前不能支持：真实缺陷检出率、修复成功率、显著性或泛化提升。目前仅一位试听者、两个来源章节，且同一人已听过原始版本并做过标注，不能作为独立盲评验收。当前四类标签没有任何阳性，两个边界也未分配 train/dev/test；本次仅校验与汇总，不生成训练集或训练模型。

用户建议的 0.2–0.4 秒音量渐入尚未实施、未验证，不能依据本次偏好认定有效。后续先针对第一章的起句衔接比较受控处理，并核验首字清晰度与原文保留；正式模型实验还需要更多独立来源及真实缺陷阳性、困难阴性样本。
