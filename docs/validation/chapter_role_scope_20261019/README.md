# 人物列表统一章节范围

用户确认采用当前章人物默认可见、标注段落数、可展开全书候选的方案。

## 行为

- 「当前核对章节」放在章节叙述者、逐段核对共用区域。
- 两处人物候选及「本段由谁朗读」统一使用该章实际朗读人物，标签为「姓名 · 本章 N 段」。计数包含叙述和对白，不随待核对/对白筛选改变。
- 「显示全书人物」默认关闭；开启后列出项目所有已配置声音的人物，未参与本章者标注 0 段。未配置声音的索引实体不会被当作可合成角色。
- 音色计数和匹配段落限于当前章，保存后继续下一段不跳到其他章。展开全书人物仅扩大候选，不扩大段落范围。
- 切换章节或候选范围时重置人物筛选；当前音色仍有效则保留。保存后当前人物暂时变为 0 段时保留该选择，明确显示空结果，避免偷偷跳到其他人物。
- 人物合并及声音档案保护保持全项目范围。
- 不修改已有书籍、人物归属或音频，不调用 DeepSeek/MiMo。
