# 网页克隆参考与本地质检接线

2026-10-17。继续打通 MiMo 网页生成流程，未开展论文实验、其他引擎适配或新增语音合成。

发现的问题：网页保存的克隆参考已经进入合成请求，但未提供独立的人工核验参考注册表时，统一质检不会用这条参考做声音比对，报告只显示没有一致性参考。

实现：

- 在章节合成前读取克隆档案指向的同一份 PCM16 WAV，核对 SHA256 和实际信号；静音／严重削波参考不作为质检锚点。相同路径和指纹的信号特征在本章复用。
- 本地质检比对参考与生成音频的声纹和音高，参考类型明确为 `clone_conditioning_reference`，保留实际文件指纹。既不生成内容核验结论，也不补造人工确认；没有参考正文，不进行参考语速比对。
- 显式配置、与当前角色／版本／语言／请求匹配的人工核验注册表仍优先。不会将克隆生成的第一块保存成已核验身份锚点。
- 默认自动修复设置不变；未校准的声纹阈值只产生疑似偏移，不自动宣称一致性通过。ECAPA 仍要求至少三秒有效语音，模型缺失或片段太短时保留未完成状态。

验证：

- 定向16项通过，覆盖指纹绑定、错误信号排除、不冒充内容／人工／语速核验，以及两章真实管线调用使用同一输入参考、复用已有合成缓存、人工注册表优先、无已核验锚点写入。管线的合成请求为替身，不访问服务。
- 使用历史已接受的原 R001 与克隆章 R051、本机已有 ECAPA 权重做离线接线验证，实际返回声纹余弦距离约0.163，类型为克隆输入参考，一致性状态仍为 `incomplete`。未运行 ASR、未传入正文、未新增听感结论。详见 [本地模型结果](local_model.json) 和 [模型日志](local_model.log)。这个距离不是准确率或跨书籍阈值验收。
- 完整636项：606通过、30按环境跳过，无失败／错误，见 [回归日志](unittest.log)。沙箱外离线运行。

本轮不改变页面布局和动态效果，也没有浏览器视觉验收。新书完整生成及最终听感仍需实际生成结果证明。
