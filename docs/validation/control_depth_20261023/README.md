# 剧本状态与控件层次验证

本次调整 Vue 前端的状态卡和交互控件，使用独立的本地离线服务验证，未调用 DeepSeek。

- 波形由 7 根增加到 15 根，桌面宽 117px，窄屏宽 87px。生成中沿用波形动画，完成后保持绿色静态波形。
- ≥1100px 时状态摘要放左侧，进度条和四个处理阶段集中到右侧；窄屏保持上下布局。1440px 视口实测完成态卡片高度约 102px。
- 浅色、深色分别定义按钮、输入面、轨道和滑块拇指的阴影；按钮包含悬停和按下反馈，输入框保留键盘焦点环。
- 引擎分段选择器只抬高当前滑块，普通导航项和文字按钮保持轻量；主生成按钮保留原有玻璃效果。

验证：`npm run build` 通过；`npm test` 共 12 项通过；Impeccable 静态扫描无发现。浏览器控制台无错误。

浏览器实测 1440×1000 浅色与 390×844 深色，均无横向溢出；输出格式选择、流式合成开关可正常修改和恢复。确认浅色与深色的控件阴影均生效，并检查了生成中 37% 与完成态 100% 的布局。
