# DeepSeek 拆分停止操作

沿用现有 Apple 玻璃工作区、深浅主题及完整动态，不替换视觉系统。

- 生成按钮右侧常驻「停止拆分」，空闲禁用，运行可点；同组按钮最小高度48px，窄屏沿用Gradio自适应排列。
- 点击停止后显示「正在停止拆分」，禁用两个按钮；实际后台清理完成才显示「已停止拆分」并恢复生成按钮。
- 仅停止当前会话拆分；更换上传文件不改变任务归属。取消排队中的三个拆分入口，停止处理使用独立队列。
- 未完成结果不保存，保留旧剧本但撤回旧确认；若停止前已保存完成，正常展示完成的文件和角色表。
- 保留忙碌阶段声轨动画，停止及取消状态不再循环忙碌；不新增虚构百分比。
