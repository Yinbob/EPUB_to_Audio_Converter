# 弹出列表层级修复（2026-10-19）

用户要求检查所有弹出列表，报告「剧本归属」「角色声音」的长列表被下方音频检查卡片遮挡。本轮修复共用菜单祖先路径的层级与裁剪，不改变现有玻璃主题、菜单定位及动态效果。

## 源码修改

`audiobook_generator/ui/web_ui.py` 约 3280 行起：卡片的 `fadeUp` 使用 `both` 保留 opacity 层叠上下文，原来仅提升卡片直接子层不足以越过后续卡片。菜单展开时将所在 `.app-card` 提至 `z-index: 20`，内部整条祖先路径提至 `2` 并允许溢出；菜单关闭后恢复。

包含该卡片的主 tabs 与 `role=tabpanel` 路径也在菜单展开时提升至 `20`，但 `body.modal-open` 时禁用此提升，避免把高级弹窗困在遮罩之下。保留顶栏 `100`、弹窗 `1000` 的层级；高级弹窗内仅对 `.modal-scroll` 内部菜单祖先路径应用相对定位、层级 `2` 与溢出放行，保留 `.modal-box`、`.modal-scroll` 自身裁剪和滚动。

不改菜单 fixed 定位坐标，不添加 transform／filter，不修改动画或 `ul.options` 自身滚动。资源库旧的 `120`／`121` 独立提升规则已删除，改用共用规则；其列表尺寸与文字换行保留。
