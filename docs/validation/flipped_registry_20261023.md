本次修改：

- 人物卡片仅携带当前块可定位的姓名和已确认别名，不提供本块不存在的全名。
- 姓名、别名只差大小写时，从已定位的原文中恢复原始写法；姓名引文仍须是原文的精确子串，并包含带词边界的人物称呼。不做翻译、补全或模糊姓名合并。
- JSON、姓名、别名或证据校验失败时，反馈具体字段和错误原因，最多纠正重试一次。失败响应不写入成功检查点。
- 修复姓名首尾空白导致后续入库静默跳过的问题。
- 整章复测还发现模型把 `narrator_identity` 填入 `text_kind`。明确该值仅属于 `evidence[].kind`；分段重试传递具体校验错误，不再原样重复失败请求。
