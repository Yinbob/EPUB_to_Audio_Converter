# 资源库文件按钮选中态（2026-10-19）

用户要求选中文件按钮状态保持，切换时不变化。用户随后明确：点击另一个文件后，前一个文件的选中外观改变。本轮按选中外观与hover／focus混淆进行局部修复，没有扩大为跨书籍或跨会话勾选持久化。

## 设计与修改

保留现有 Apple 玻璃、双主题及动态。移除 web_ui.py 中旧 .file-checks 渐变与通用hover，并移除触屏 background:revert 规则对文件按钮的匹配；在 workflow.py 单独维护资源库文件行样式。

选中由 input:checked 决定，普通、悬停、按下、聚焦均使用同一蓝色浅底与蓝色边框。鼠标悬停只对未选项使用中性底，键盘焦点使用内侧描边，保证滚动容器内可见。复选框勾选时显式蓝底，避免全站输入框玻璃底覆盖。

文件行最小48px高、14px圆角、13px/16px内边距、8px行间距，选前选后字体与尺寸固定。颜色与边框过渡160ms，继续继承既有动态偏好，不改文件操作、试听或搜索的数据规则。
