# 人物叙述与旁白声音归属

2026-10-17。解决多视角第一人称书籍被统一分配默认旁白的问题，修改自动剧本生成到声音计划的链路。

实现：

- 段落新增可选 `text_kind`：narration／dialogue／unknown；`role_id`继续表示实际声音身份。人物自述、回忆和相应动作叙述可以使用人物角色，复用其对白的内置／描述／固定参考声音，不另建一份旁白声音。
- V2自动拆分每个所选章节增加一次DeepSeek叙述视角请求，使用原文和已有名称卡片，输出有原文引文的身份候选；每章独立判断，不继承上章身份。24000字符以内提供完整本章正文，超出取首尾各12000字符并明确中段未提供。预分析不额外重试，失败继续原有逐段识别。
- 分段模型结合本章候选确定各段身份，保留章内实际视角变化。候选不是全章覆盖规则。第三人称聚焦、对白中的“我”和提到某个人的姓名，都不等于叙述者身份；提示词明确禁止按书名或章节奇偶猜测。
- 人物叙述必须有当前章中可唯一定位的 `narrator_identity` 原文引文；缺失／编造／重复无法定位的引文使该叙述退回默认旁白并标记待复核。引文可在同章前文，允许跨越600字符的分块距离。文字与原文逐字覆盖、稳定实体与声音档案、原始引用坐标仍走正式校验。
- 机器归属仍为未校准提议；原文存在的引文不能证明模型的语义推断正确。第三人称默认旁白也供核对，不要求每段单独向用户提问。旧JSON可不含新字段；重新拆分才补出类型。只保留明确human归属，旧机器默认confirmed旁白不会挡住重新识别。
- 网页现有「剧本与归属」摘要增加叙述声音列，段落详情显示用途和声音身份，使用现有人工归属入口修正，之后重新确认生成。没有新增折叠区或改动主题、动效。

离线验证：完整649项中619通过、30按环境跳过，无失败或错误，见 [完整日志](full.log)。新增7项叙述核心测试与1项网页读出测试，覆盖两个人物跨章自述、同人叙述和对白共用声音、项目保存重载及正式合成计划、身份引文缺失／伪造退回、同章远处证据、人工决定保留与旧机器默认重识别、预分析失败及所选范围隔离、长章输入界限和无效新字段拒绝。

上述最初离线验证阶段的模型响应由本地测试替身提供，测试正文为自编短句；该阶段没有向DeepSeek发送《Flipped》第一／二章，没有调用真实MiMo，也没有改写已试听音频或既有人物项目。本轮证明工程行为，不证明模型在《Flipped》或任意新书上的实际识别准确率。浏览器工具既有访问限制仍有效，未绕过，未进行新的浏览器验收。

使用方式：刷新页面，选择所需章节并重新生成剧本，再查看「剧本与归属」中的叙述声音，为对应人物试听和确认。操作见 [网页使用说明](../../MiMo网页生成使用说明.md)。

## 缺失类型校验与最终候选

后续检查确认，修订版开头659字符的unknown类型会使「本章叙述声音」整章纠错跳过该段。因此新增正式拆分校验：启用叙述识别时，非空段落若漏返或返回无效`text_kind`，进入原有每块最多2次的重试；不会增加重试上限。两次仍不合格时保留可对齐原文并标为unknown供复核，显式unknown也不强行改判。旧调用未启用叙述识别时保持兼容。

在同一用户授权和总20次上限内，通过[classify_flipped_opening.py](classify_flipped_opening.py)仅对第5章0～659字符追加1次请求。原始响应保存在gitignored的`opening_classification/response.json`；模型明确返回narration及相同Bryce稳定人物ID，经过严格原文对齐与身份引文检查后，另存`machine_proposal_final.json`，此前两版提议均保留。没有新增人物索引或整章预分析，没有处理其他章或生成语音。

最终共19次文字请求：第5章index=3、narration=1、split=6；第6章index=3、narration=1、split=5，均在授权阶段与总次数上限内，剩余1次未使用。见[最终请求元数据](flipped_requests.json)。

[最终离线审计](flipped_probe_final_audit.json)及`audit_flipped_probe.py --final`确认：两章分别完整覆盖14311／12943原文字符，段落均有有效类型；第5章13180叙述字符全归属Bryce，第6章12423叙述字符全归属Juli，没有叙述退回默认旁白，自述和本人对白共用人物／声音档案，初次对白声音归属未变。另在内存中实际调用整章纠错，确认开头随全部叙述一起变更，对白、另一章及声音参数不变；该纠错检查未保存到任何人物项目。

新增两项回归覆盖：漏返类型后在现有上限内重试并复用人物身份；持续漏返时不丢原文、不冒充已分类、没有追加第三次请求。最终[聚焦检查](type_validation_focused.log)39项通过，[完整回归](type_validation_full.log)661项中631通过、30按环境跳过，无失败错误。这是本轮最终代码的验证记录，上一节659项是此前证据复用改动的历史记录。

最终候选仍为机器提议，后续微调使用了首轮模型上下文和缺陷定位，不是全章独立盲测；没有实际TTS音色／听感或新浏览器视觉验收，既有Flipped人物项目及音频均未覆盖。
