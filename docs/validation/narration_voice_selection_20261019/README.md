# 章节叙述声音选择修复（2026-10-19）

用户报告《Flipped》第二章推荐男声，随后明确：在「角色声音」中选择「旁白」时显示男声。

## 查证与原因

- 当前项目的 Flipped 章（EPUB 目录第 6 项）10 段叙述均归属 Julianna，女性，已存声音为 Chloe；段落已人工确认。不能从这个已修改的存档还原最初全部模型输出。
- 原声音选择器默认选 roles 的第一个角色，即独立 narrator；它并不等同于该章实际自述人物。用户看到的是默认旁白声音，与本章人物声音混淆。
- 另发现后台缺口：分段结果已经包含角色，但性别缺失或 unknown 时，原 setdefault 不会补回章级分析识别出的女性信息，后续可能使用无性别默认选声。该缺口已用离线夹具复现。

## 修改

- 首次打开声音配置优先选择首个有叙述段章节的唯一叙述人物；切换章节同步选择对应人物。保留用户明确选择，不为多叙述者章节猜测唯一声音。
- 独立 narrator 标为「默认旁白（独立于人物自述）」，声音设置说明自述与对白共用人物配置。
- 章级提示明确展示「项目已保存的叙述声音」，说明本次调整以「角色声音」设置为准，避免未保存表格参数与存档提示混淆。
- 同一 ID 且被当前块引用的角色，补齐缺失姓名或未知性别；保留明确值，不修改段落归属。
