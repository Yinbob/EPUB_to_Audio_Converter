# 人物索引容错机制验收

用户选择：少量异常转为警告并继续，保留有效人物，异常归属待复核。

## 行为

- 姓名、别名与证据引文只差大小写、空白、全半角或常见引号／横线时，恢复为原文切片。保留英文单词边界；存在歧义时不自动匹配。不同拼写、翻译或补全的全名不会被猜成同一个人。
- 保留原有最多两次请求。第二次仍有语义错误时，每个分块的异常人物条目数量不超过 `max(1, floor(条目总数 / 5))`，且至少有一个有效人物，才允许继续。
- 排除无法定位的人物条目；人物姓名与证据有效、只有别名异常时保留人物并排除异常别名。每个人物条目只计一次异常。
- 全部无效、异常数量超限、JSON／数组损坏、取消或网络失败仍按现有失败机制处理。
- 提示随 V2 剧本保存到可选字段 `registry_warnings`；含提示的索引不标记为完整。Vue 多角色模块常驻提示、可展开详情，Gradio 摘要也显示提示。
- 受影响章节的自动归属标为 `needs_review`，原文不删改；原文区间与正文未变时保留人工确认。
- 降级分块不作为完成断点缓存，下次生成可以重试。恢复成功后清除相应范围提示；其他章节提示继续保留，已有有效人物及声音配置继续复用。
