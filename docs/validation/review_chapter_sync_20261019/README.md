# 核对章节跟随生成章节

原行为在载入剧本时读取旧的核对章节值，没有使用生成页的章节选择；没有旧值时退回第一处已有叙述的章节，因此选择第 11 章仍可能显示第 5 章。

现在剧本载入/拆分完成和生成起始章变化共同触发 `load_narration_controls`，以生成页起始章节为默认核对位置。按名称选择章节后，目录选择器更新起始章数字，随后同步核对章节。范围选择默认核对起始章；用户仍可手动核对其他已保存章节，手动核对不反向修改生成范围。保存人物归属和合并后的刷新继续保留当前核对位置。

指定章节尚无剧本时，用「章号 · 尚未生成剧本」保留所选位置，禁用叙述者修改并说明下一步，人物和段落筛选不展示其他章内容。只有未指定章节的旧调用才保留原先首次可用章节的默认逻辑。
