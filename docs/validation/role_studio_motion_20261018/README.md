## 实现

- 拆分状态卡使用声轨波形、流动轨道、实际阶段与持续计时；不展示估算百分比。完成和失败时停止循环动画。
- 试听播放器上方留白为 24px，窄屏为 20px。
- 操作按钮增加按压回弹。确认按钮先显示核对状态，后端确认通过后切换绿色与勾选动画；失败恢复可操作，参数变动后撤回成功状态。成功状态由后端确认标记驱动。
- 保留用户要求的完整动态效果、已有玻璃材质和主题色。动画作用于按钮或装饰叶节点，不给下拉菜单祖先添加 transform/filter。
