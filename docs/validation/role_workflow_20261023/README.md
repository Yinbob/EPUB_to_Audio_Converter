# Vue 多角色配音流程整理

2026-10-23，沿用现有深浅主题与玻璃样式，调整模块内部信息顺序。

## 修改

- 四步导航：准备剧本 → 人物声音 → 段落归属 → 复核与确认。无剧本时后续步骤禁用，载入或导入项目后进入人物声音；编辑步骤提供下一步按钮。
- 全书声音分配置于人物声音步骤，与逐人物配置并列；导入剧本／载入项目、人物索引范围默认折叠。
- DeepSeek 拆分任务不再占用页面顶部的全局进度卡片；模块内展示实时日志、阶段、百分比和停止按钮。普通音频生成的全局进度保持原行为。
- 无百分比时显示不定进度，不伪造数值；有后端百分比时按真实值显示。刷新后若发现运行中的拆分任务，自动展开多角色模块。
- 准备按钮在整个提交、准备、运行与停止阶段显示忙碌状态，增加 24px 旋转标识；状态波形加粗、增加动态进度条。动画只改变 transform；沿用已有缓动令牌，提供 reduced-motion 静态反馈，模块收起时暂停动画。
- 底部说明指向模块内部进度；运行中刷新后不再提示重新上传文件。

## 验证

- `npm run build`：Vue 类型检查与生产构建通过，已更新 `frontend/dist`。
- `npm test`：2 个文件、12 项单元测试通过。
- Impeccable 静态检测：`[]`；`git diff --check` 通过。
- 使用电脑工具和独立临时服务进行浏览器交互验证。模拟任务，无 DeepSeek／TTS 调用，无用户项目写入。
- 运行中刷新自动展开多角色模块，顶部 `.progress-card` 不可见；模块内显示忙碌按钮、不定进度动画与停止按钮。
- 模拟百分比切换为 37，模块内显示 37%，进度条 `aria-valuenow=37`。
- 导入区域默认关闭，展开后可选择项目并载入；进入人物声音后可通过下一步到段落归属、复核与确认。
- 对临时项目点击确认后显示「修订 1 · 已确认，可生成」。
- 模块内停止按钮使模拟任务变为停止状态，忙碌动画结束。
- 1440×1000 桌面与 390×844 窄屏无横向溢出；窄屏步骤为两列。深色窄屏运行态已检查。
- 最终页面控制台 error 查询为空。更新了既有 E2E 用例中的折叠入口操作，本轮未执行 Playwright CLI 套件，交互验收使用电脑工具。
