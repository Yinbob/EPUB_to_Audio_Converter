# Vue 上传与交互调整（2026-10-21）

本次沿用原苹果风、毛玻璃和深浅主题，仅修改上传、展开项、切换和按钮交互。

- 上传区恢复旧版约 300px 高的虚线拖放框、圆形上传图标、悬停上移 3px、按压 0.99 倍反馈；隐藏原生文件按钮，保留整个区域点击、拖放和键盘聚焦。手机高度 240px。
- 单本上传后自动读取目录；更换引擎或解析选项重新读取。180ms 合并相邻变更，取消过期请求并核对请求版本；批量上传回到数字范围，不沿用单本目录。读取失败提供中文说明与重试，未完成读取时禁止提交生成。
- 所有原生 details 统一细分隔线、轻量标题和旋转箭头。支持的浏览器使用 200ms 内容展开；其他浏览器保留原生展开，不依赖脚本或隐藏业务状态。
- 主导航、六引擎、角色工作台和下载方式共用滑动分段控件。滑块使用 transform，250ms；页面沿切换方向位移并淡入淡出，260ms，生成页的 KeepAlive 草稿保留。
- 页面移动时临时取消卡片的大面积 backdrop 模糊，避免逐帧重算；动效结束恢复原材质。位移区域裁剪防止手机横向溢出。
- 表单布尔项使用滑块开关，原生 checkbox 语义、标签、禁用、键盘空格保持有效；资源多选列表继续使用勾选框。减少动态效果偏好关闭位移动画；键盘触发的导航即时切换。
- 补齐 Field 的独立无障碍名称；损坏书籍解析返回结构化中文 422，避免自动读取触发非 JSON 服务器错误。
