# Vue 布局与剧本入口修复（2026-10-23）

按用户要求先制定计划，依次完成宽度、章节范围、引擎切换、试听折叠、角色展开和 DeepSeek 入口六项修改。

## 实现

- 查阅 `63aa489`（新增多角色对话生成功能）：原内边距为 `clamp(14px, 4vw, 48px)`，桌面容器上限为 1280/1320px。Vue 原先已经保留这两档上限；本次按“减少两边留白”的要求保留内边距，取消桌面上限，让工作区随窗口伸展。
- 恢复 Gradio `chapters.py` 的全书范围蓝条：按章节索引定位起点、按所选章数占全书比例显示长度，显示起止标题与字符数。无效范围收起蓝色填充并提示纠正。
- 切换引擎期间保留目录和所选范围，收到新目录后再更新；缓存已读取目录，取消过时请求，避免重复清空上方卡片。关闭生成页的浏览器滚动锚定。
- 主声音试听区默认关闭，展开后才显示试听文本、开始试听按钮及音频。
- 开启多角色时保留上方逻辑声音卡的位置，仅禁用整书声音选择。角色工作区通过 grid 向下展开，首次打开才挂载，后续收起保留编辑状态；关闭时禁止焦点进入。整体开关不再按压缩放。
- 突出「DeepSeek 生成剧本」按钮，复用现有 `/api/v1/tasks` 的 `kind=split`、DeepSeek 设置与项目结果链路。状态区覆盖等待、提交、准备、运行、完成、失败、停止；阶段依据真实日志，不模拟百分比。等待波形仅在运行且可见时播放，支持减少动态效果。刷新期间已运行的任务也能在重新展开后保留终态。
