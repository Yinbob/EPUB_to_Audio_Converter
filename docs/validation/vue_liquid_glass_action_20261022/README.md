# 生成按钮液态玻璃样式

日期：2026-10-22。

底部生成按钮使用半透明中性玻璃、背景模糊和双层反射高光。原大面积彩色渐变改为两像素彩色折射边缘，中央保持清晰的主题文字。停止状态沿用玻璃材质，以红色文字、停止图标和红色边缘区分。

- 保留生成、停止、提交中、禁用及焦点反馈，不修改后台逻辑。
- 提供低透明度偏好、高对比度模式及不支持背景模糊或遮罩的降级样式。
- 正式构建及类型检查通过，9 项现有浏览器用例通过，含启动、刷新恢复、停止提交期间禁用与只发起一次停止请求。
- 已检查桌面 1280 × 900、手机 390 × 844 的深浅主题及停止状态，无横向溢出。仅一轮视觉检查，无额外视觉迭代。
- 使用离线轻量任务验收，未调用真实模型或付费语音接口。
