# 玻璃曲面高光与慢速霓虹流动

2026-10-22：移除原先均匀的七像素模糊彩环，改为玻璃内外两层细高光、端部曲面反射和略有色差的内侧光弧。中央继续保持透明，不移动文字或图标。

霓虹亮段沿圆角矩形周长匀速移动，每圈 36 秒；内侧折射光弧同步移动并保留位置差。使用 SVG 路径实现沿边缘行进，没有旋转整个按钮或更新 Vue 每帧状态。不可见或页面隐藏时暂停；禁用、停止和高对比度状态不播放霓虹动画，减少动态效果时保持静止。

正式构建及类型检查通过，9 项浏览器用例通过。新增运行态验证确认路径偏移确实变化、文字位置稳定、速度不快于 30 秒一圈、离开视口暂停、减少动态效果时静止。桌面与手机、深浅主题已检查，两轮视觉检查完成。没有请求真实模型或付费接口。
