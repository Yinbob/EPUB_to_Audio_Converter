# 配音开关、生成操作与顶栏交互

日期：2026-10-21。

- 多角色配音使用独立模式开关：人物图标、状态文字、渐变滑轨和勾选滑块。点击提供 160ms 按压反馈，切换使用 250ms 滑动；保留原生复选框键盘操作、引擎禁用条件和焦点提示。
- 生成按钮采用青蓝、蓝、紫、玫红渐变，深浅主题分别配置。后端确认任务启动后切换为停止按钮；停止提交期间禁用，完成后恢复生成入口。刷新后没有本地已选文件仍可停止后台任务。其他耗时任务显示「停止任务」。
- 点击顶栏品牌或空白处回到当前页面顶部，不切换路由；主题按钮不触发回顶。减少动态效果时直接回顶，开关不播放位移动画。
- 正式构建和类型检查通过；6 项单元测试、9 项浏览器测试通过。停止流程使用临时数据和轻量后台任务，确认停止请求提交期间不会重复触发。
- 桌面 1280 × 900、手机 390 × 844 的深浅主题已检查，无横向溢出。截图采用减少动态效果模式。
- 验收中明确重置前一用例持久化的「仅解析」选项；主题切换的滚动断言允许小于 20px 的布局变化，验证其不会回顶。
- 未请求真实模型或付费语音接口。
