# 首页长页面与锚点导航验证

日期：2026-10-23。

五个模块改为同时纵向展示，保留独立卡片。五步入口使用普通页内链接，导航不吸顶；品牌栏维持原有吸顶行为。点击后平滑滚动并将焦点移到目标模块，滚动留白取品牌栏高度、顶部位置与 16px 间距。减少动态效果时使用即时定位。任务状态更新不执行滚动。

## 已执行验证

- `npm run build`：Vue 类型检查和生产构建通过，已更新生产资源。
- `npm test`：2 个文件、12 项单元测试通过。
- `git diff --check`：通过。
- 使用隔离的本地服务和 `covered-book.epub` 离线夹具进行浏览器交互；未调用 DeepSeek 或语音接口。
- 桌面 1440×1000：五个模块始终可见；五个入口均能移动焦点并滚动到对应模块；键盘 Enter 可定位。声音模块顶部约 100px，品牌栏底部约 85px。
- 手机 390×844：五个模块始终可见，无横向溢出；声音模块顶部约 92px，品牌栏底部 76px。
- 导航为 `position: static`，下滑后完全移出视口；品牌栏继续留在顶部。手动下滑时高亮更新到多角色模块，到达页面末尾后更新到生成模块。
- 上传书籍及章节读取正常，跨模块浏览后书籍、语速 1.25、多角色开启及展开状态均保留。
- 浏览器控制台没有错误；导航底部提示文字保持移除。
- 页面末尾采用浏览器正常滚动边界，不为强制顶对齐增加空白区域，模块标题保持在品牌栏下方。
