# 首页流程导航与日志排版验证

沿用 Vue 现有玻璃材质、控件阴影和深浅主题，参考 Gradio `audiobook_generator/ui/workflow.py` 的编号入口、说明文字与下一步提示。

## 实现

- 日志页的任务选择与自动更新分为两列，标题在上、交互面在下。桌面两块交互面均为 46px 高，实测 top 436.984375px、bottom 482.984375px，边缘完全对齐；窄屏上下排列并保持等宽。
- 首页依次提供「书籍与章节 → 选择声音 → 多角色配音 → 音频检查 → 确认与生成」。多角色明确标为可选，提示随上传、剧本确认和任务状态变化。
- 导航滚动后停靠顶栏下方，根据阅读位置高亮。点击定位并聚焦模块标题，不自动开启开关、不发起生成任务。指针点击平滑滚动；键盘和减少动态效果偏好使用即时定位。
- 动态测量顶栏与流程导航高度，保证标题不被遮挡。模块展开、视口变化及首页缓存恢复后重新测量；离开首页停止监听。页尾保留仍可见的选中模块，避免点击音频检查时错误高亮生成步骤。

## 验证

- `npm run build`：通过，包含 Vue/TypeScript 检查及生产构建。
- `npm test`：12 项通过。
- Impeccable 静态扫描无发现，`git diff --check` 通过。
- 独立本地离线服务使用两条临时任务验证选择、日志读取与自动更新开关；未请求 DeepSeek 或语音接口，未修改用户项目和日志。
- 浏览器实测桌面 1440×1000 浅色、手机 390×844 深色，页面无横向溢出。五个入口逐项键盘定位，焦点均到对应标题；手机点击多角色入口后开关仍关闭。
- 桌面定位前几个模块时标题位于导航下方约 16px；手机导航底部 209.4375px、多角色模块顶部 224.640625px。手动滚动后高亮更新，控制台无错误。
